FFmpeg source code

CineWise uses the audio decoders of FFmpeg 8.1.3 under the GNU Lesser General Public License, version 2.1 or later. We did not change the FFmpeg source. These are the exact files that we built from:

  • ffmpeg-8.1.3.tar.xz: the FFmpeg source (SHA-256 7138d28c96d9d3e3af4ee3d8cad72741f8ffb40da90c1112235dea3ecd3178a3)
  • ffmpeg-8.1.3.tar.xz.asc: its signature by the FFmpeg project
  • build_ffmpeg_lgpl.sh: our build script, with the exact configure options
  • LGPL_PROOF.txt: the build record that shows the LGPL configuration
  • README.md: how to build the libraries and replace them
  • CMakeLists.txt and ffmpeg_jni.cc: the Media3 code (Apache 2.0) that links to the FFmpeg libraries
  • FFmpeg-COPYING.LGPLv2.1: the licence text
